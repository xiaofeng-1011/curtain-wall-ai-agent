# 幕墙方案助手（v0.3：聊天式交互与空白启动）

依据《幕墙智能体：聊天式交互与空白启动改版方案 v0.3》。打开时是一个空白的聊天助手：没有任何预装项目、材料、价格、规则或资料。你描述方案，它整理参数、一次只追问一个缺项，计算立柱横梁理论用量并比较材料金额，每个数字都能追溯到输入和公式。

覆盖范围：构件式玻璃幕墙、单矩形等距立面、铝合金立柱与横梁的理论轴线用量及未税材料金额。不含玻璃、五金、加工、损耗、运输、安装；不作结构安全验算、施工图审查或工程签审。

## 启动

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

在线理解（可选，默认 DeepSeek V4 Pro）：把密钥写入 `.streamlit/secrets.toml`：

```toml
DEEPSEEK_API_KEY = "sk-..."
```

没有密钥或请求失败时自动使用本地解析，消息下方会注明；也可以随时点“查看参数”用表单填写。

## 怎么用

在底部输入框直接说，例如：

1. `手工测试甲，构件式玻璃幕墙，宽18m、高6m，分格宽1.2m、高1.5m。本次数据为演示数据。先算型材用量`
2. 助手问“立柱每米多重？”，可一次回答：`立柱 2.7kg/m、25 元/kg，横梁 1.3kg/m、28 元/kg`
3. 第一次计算前确认一次参数和计量口径 → 结果卡：面积、长度、质量、金额
4. `把分格宽改为1.5m，与原方案比较` → 建立调整方案（其余参数沿用原方案）并给出差值
5. `为什么立柱用量变了？` → 引用两套方案的计算步骤解释
6. `再改成2m`、`撤销`、`原方案高度填错了，应该是 9 米`、`沿用刚才的价格`、`分格高再增加 100 毫米`
7. 结果卡上：查看计算依据、下载 Excel 比选表；“更多”中有技术追溯包（ZIP）

其他入口：粘贴 Excel 表格或上传 `.xlsx/.csv`（识别后预览，确认才写入）；左栏“规范问答”打开独立规范会话，无需建立项目即可选择资料集、标准、版本和专业类别，使用“查找原文”或“基于资料回答”。回答的每个实质性摘录带引用 ID、原始 PDF 页和质量提示；点击引用可查看或下载已登记的原始 PDF。左栏“资料库”仍用于普通上传资料；OCR 成果包必须在“规范问答 → 管理规范库”中导入，不能递归上传整个成果目录。

规范成果包导入也可在命令行执行（不会重跑 OCR、不会写入原始目录）：

```powershell
python tools/import_standards.py `
  --source "path/to/standards" `
  --package "path/to/processed-package"
```

导入结果保存在当前工作区 `data/workspace/standards/import_report.json`，随后会生成本地 FTS5 索引。再次执行是增量导入，未变化的文档不重复写入；索引在明确执行导入更新时构建，问答过程不重建索引。索引过期或源资料变化时问答会停止引用并提示更新。完整使用与验收记录见 [规范问答使用与验收.md](规范问答使用与验收.md)。

## 数据与来源

- 工作区在 `data/workspace/`（可用环境变量 `MW_RUNTIME_DIR` 指定）。新目录为空；清空后重启仍为空；程序任何路径都不会自动装入演示数据。
- 你说“测试／演示数据”时，本轮录入值标为 synthetic；未声明出处的输入标为“来源待核实（用户提供）”；“来自真实项目”也不会自动变成已核验。确认参数用于计算 ≠ 专业复核。
- 规则：默认 0 条。可在“查看参数 → 核查规则”中自己建立演示规则；正式条款 0 条，结果不会写成合规结论。
- 删除：对话／项目先进入回收站（可恢复），在回收站中“彻底清理”才删除记录、快照、导出与附件；已下载到电脑的文件不在应用内清理范围。
- 旧版 v0.2 数据（`data/runtime/app.db`）首次打开时提供一次选择：保留为项目、移入回收站或暂不处理；迁移前自动备份，不会自动删除。

## 测试与验收

```bash
python -m pytest
python tools/acceptance.py
```

`tools/acceptance.py` 运行全部自动化测试（每个测试一个独立空白工作区，本地解析模式），按改版方案 §9 的 T01–T38 生成《验收记录.md》，并实测性能（设置了 `DEEPSEEK_API_KEY` 时另测在线理解耗时）。T10/T11 的参考值在 `tests/fixtures/manual_expected.json`（按 §9.5 公式手算），被测代码不读取。`tests/fixtures/demo_package/` 是旧版演示包，只用于计算内核的回归测试。

## 目录

| 路径 | 责任 |
|---|---|
| `app.py`、`ui/chat.py`、`ui/style.py` | 单一聊天界面、结果卡、参数／依据／设置弹窗；不含计算公式 |
| `agent/assistant.py` | 会话编排：理解 → 修改草稿 → 一次一问 → 确认 → 计算 → 解释／检索／导出／删除请求 |
| `agent/extraction.py`、`agent/parser.py` | 在线模型理解（带项目上下文、结果校验）与本地解析降级 |
| `agent/projects.py` | 项目、原方案／调整方案（继承）、材料与报价（写时复制）、来源、撤销 |
| `agent/planner.py`、`agent/engine.py` | 分任务门槛与部分结果；冻结快照并运行确定性工具 |
| `agent/importer.py`、`agent/documents.py` | 表格导入（粘贴／CSV／XLSX）与资料库 |
| `agent/migration.py`、`agent/package_import.py` | 旧版数据迁移；技术 JSON 数据包（维护用途） |
| `calculation/`、`validation/`、`evidence/`、`domain/` | 确定性计算、校验、规则引擎、单位与契约（沿用 v0.2 内核） |
| `storage/workspace.py`、`storage/snapshots.py` | 工作区存储、回收站与清理；不可变快照 |
| `reporting/` | 报告、Excel 比选表、技术追溯包 |

## 已知限制

- Streamlit 原型：单用户本地使用；无法在处理中途停止请求；向上阅读时新结果出现后页面不会提示“有新结果”。
- 在线理解单轮约 5–8 秒；启用后用户输入会发送给模型服务商，接入企业真实数据前需确认保密与部署方案。
- 只支持普通单表或简单工作表的 Excel；Word 资料检索、扫描件 OCR、复杂合并表格尚未支持。
- 只支持一个原方案和一个调整方案；三个及以上方案比较为后续工作。
- 规范资料已登记 91 份目标文件（89 份处理完成、2 份处理失败），另记录 3 个经 SHA-256 核验的重复别名和 3 份排除项；登记 6,833 页，其中已处理资料 6,810 页。可检索 89 份 / 6,772 页；经片段级数值、结构、正文/说明和质量筛选，可参与参考摘录的是 65 份中的 1,557 页 / 4,495 个片段，其余可检索的 5,215 页仅用于定位。还有失败文件 23 页、已处理文件无可检索正文 38 页。无文字不代表已确认空白。全部资料专业审核仍为“未复核”，现行状态仍为“待核实”。
- 规范问答会话不写入项目参数、计算快照、材料价格或正式核查规则。数值、表格、公式、否定词和已知 OCR 问题页会被限制为原页定位；原始 PDF 才是复核依据。
