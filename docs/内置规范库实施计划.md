# V4 内置规范库实施计划

1. 沿用规范导入、检索、质量门槛和引用原件校验；发布阶段生成干净SQLite快照和索引。
2. 以稳定资料集ID和逻辑资源根管理内置资料；内容哈希校验代替开发机mtime依赖。安装只读资源与用户业务数据分离。
3. 首次启动自动校验部署、显示进度；中断重试、损坏恢复、版本更新仅替换内置集合，保护用户库。
4. 规范会话默认选择内置库，持久保存主动选择；管理入口提供维护和恢复；清理项目聊天保留规范库。
5. 重新构建Windows程序与用户级安装包，排除开发数据、配置和密钥。
6. 隔离环境验证首次启动、重启、迁移、离线原件查看、故障恢复、升级、既有业务回归；完整记录未执行的跨电脑验收。
