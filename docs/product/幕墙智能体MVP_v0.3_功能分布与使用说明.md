# 幕墙方案助手 v0.3：功能分布与使用说明

阅读日期：2026-10-12。依据当前 `../幕墙智能体MVP/` 中的实际程序，而非上一版改造计划。

本次检查了界面、聊天编排、计算入口、文件导入、资料库、材料库、删除、导出及项目自带验收记录；并在临时空白工作区、关闭在线模型的条件下实际走通建案、确认、比较、连续改参和撤销。未修改应用程序、现有工作区和模型配置，未重新进行浏览器视觉验收，也未重新运行全套自动化测试。

## 1. 这版到底能做什么

它现在是一个以聊天为入口的幕墙方案计算与资料查阅助手。可以从空白开始亲自建立项目，不必加载内置演示案例，也不必先制作 JSON 数据包。

| 能力 | 当前实际用途 | 需要注意 |
|---|---|---|
| 录入与整理方案 | 用自然语言、表单、粘贴表格、Excel/CSV 建立尺寸和材料参数 | 识别后要看回显，复杂表达不保证都理解正确 |
| 缺参追问 | 根据任务问缺失的几何、线重、单价等 | 可以回答多个参数，也可以点“暂时跳过”或先看可算部分 |
| 理论用量计算 | 立面面积、立柱/横梁理论轴线长度、型材质量 | 不等于实际下料长度或采购数量 |
| 材料金额与比选 | 两类型材未税材料金额，原方案与调整方案差值 | 不包含玻璃、五金、加工、损耗、运输、安装、税费 |
| 连续调整 | 改分格、改材料参数、继续比较、撤销、更正原方案 | 一个项目目前只有一个原方案和一个调整方案 |
| 演示规则核查 | 用户自己建立简单阈值条件，逐项检验流程 | 默认零规则；不能作为正式规范结论 |
| 资料查阅 | 在用户上传的 PDF/TXT/MD 中查找相关片段 | 本地资料库检索，不是联网查规范；上传不等于审核 |
| 追溯与导出 | 查公式、输入、来源、规则状态；下载 Excel 或技术 ZIP | 旧结果保留对应的旧参数，改参后需看最新结果 |
| 数据管理 | 重命名、回收站、恢复、彻底删除、清空工作区 | 对话、项目、个人材料库、资料库的删除范围不同 |

适用范围仍然是构件式玻璃幕墙、单个矩形等距立面。模型计入左右边柱和顶底横梁，按轴线计长，不扣柱宽与连接间隙。程序不做结构安全验算、承载力/挠度判断、施工图审查、工程签审、CAD/BIM 识别、单元式或复杂立面计算。

## 2. 功能分布：在哪里找

### 2.1 主界面

| 位置 | 名称/按钮 | 怎么使用 |
|---|---|---|
| 左侧顶部 | ＋ 新对话 | 回到一个新的空白聊天入口；不删除之前的项目 |
| 左侧中部 | 最近对话 | 点击继续某次聊天及其绑定项目；目前默认最多展示最近 40 个对话 |
| 对话旁边 | ⋯ | 重命名、删除对话；有项目时可删除项目 |
| 左侧补充区域 | 没有对话的项目 | 删除对话但保留项目后，可在这里重新打开项目并建立对话 |
| 左侧底部 | 设置 | 打开模型、资料库、个人材料库、回收站、工作区、维护六个标签 |
| 空白首页 | 录入一个方案 | 打开空白参数表单；适合不想靠聊天填数的人 |
| 空白首页 | 比较两个方案 | 显示如何描述原方案和调整方案的提示，不会自动创建两个方案 |
| 空白首页 | 查找资料 | 显示资料查询提示；仍在底部输入框提出问题 |
| 对话顶部右侧 | 查看参数 | 已有项目后出现；编辑方案、建立规则、选材料和改项目名 |
| 页面底部 | 聊天输入框及附件入口 | 发要求、回答追问、贴表格、上传文件；所有日常任务都从这里进入 |
| 结果消息下方 | 查看计算依据 | 查看本次结果的公式、来源和规则状态 |
| 结果消息下方 | 下载比选表 | 下载 Excel，即使只计算了一套方案也可下载 |
| 结果消息下方 | 更多 → 技术追溯包（ZIP） | 下载给开发或专业复核人员使用的详细材料 |

左侧“保存名称”在对话有项目时，会同时重命名对话和项目。它目前不是两套完全独立的命名操作。

### 2.2 “查看参数”窗口

| 标签 | 包含内容 | 典型用法 |
|---|---|---|
| 原方案 | 幕墙总宽/高、分格宽/高、层高、申报面积、两类型材名称/线重/单价、报价口径、数据性质 | 首次录入，或者更正原方案中填错的参数 |
| 调整方案 | 同样的参数，继承项标“沿用原方案” | 已建立调整方案后出现；可以直接批量改多个值 |
| 核查规则 | 已有演示规则、删除规则、添加规则 | 自己选参数、比较条件和阈值，验证核查流程 |
| 材料库 | 把项目型材保存到个人库；从库中选入当前原/调整方案 | 复用自己录过的线重及可选单价 |
| 项目 | 项目名和默认数据性质说明 | 重命名、了解该项目新录入值的默认来源身份 |

刚从空白首页打开表单时只有原方案录入区域。建立项目后再打开，才会看到规则、材料库和项目标签；有调整方案后才会出现调整方案标签。

填表要点：

- 只填当前任务需要的内容，不必一次填完。
- 长度选择 m、mm 或 cm；线重用 kg/m；单价可用元/kg或元/吨。
- 幕墙总高、分格高、层高是不同字段，不要混填。层高主要用于相关规则，并非所有数量计算都要填。
- 申报面积可暂留空；程序会按总宽×总高算面积。另填申报面积时，要确认与该立面一致。
- 选“测试／演示数据”或“实际资料（来源待核实）”，不要把自行构造的值当成实际工程数据。
- 当前金额计算采用未税价。选“含税（不参与金额计算）”后，不能指望程序自动扣税。
- 将已有值删为空白再保存，表示明确删除该值；调整方案清空后不会自动沿用原方案补回来。
- 保存后在聊天里说“计算材料金额”或“与原方案比较”，明确触发目标任务。
- 修改单位时同时正确填写相应数值，保存后核对回显；当前界面只切换单位而数值文本不变可能没有提交该字段。

### 2.3 “查看计算依据”窗口

| 标签 | 看什么 |
|---|---|
| 计算步骤 | 长度、质量、金额及差值的公式和数值代入；未完成部分的原因 |
| 输入与来源 | 原/调整方案参数、型材和报价、来源记录及审核状态 |
| 规则核查 | 各条已配置规则的执行结果和原因；无规则时明确说明 |
| 技术详情 | 本次运行、输入快照、版本、工具版本和技术记录；普通使用可不打开 |

这里展示的是选中那次计算的记录。顶部提示“这是历史结果”或聊天卡提示“参数已修改，以下为上次结果”时，不要把它当成当前参数的结果。

### 2.4 “设置”窗口

| 标签 | 功能 | 使用提醒 |
|---|---|---|
| 模型连接 | 查看模型是否配置及最近真实请求是否成功 | 当前没有在界面填写密钥或更换模型的表单，需要维护人员配置 |
| 资料库 | 上传 PDF/TXT/MD，导入本机资料文件夹，查看可检索页数，删除资料 | 工作区共享；不限定当前项目；上传文件一律未审核 |
| 我的材料库 | 查看已主动保存的型材，删除库条目 | 工作区共享；库条目删除是直接操作，不经过回收站；不会改写已经复制到项目中的材料 |
| 回收站 | 恢复或彻底清理项目、单独删除的对话、资料 | 项目彻底清理需勾选确认；单独对话/资料的彻底删除按钮没有同样的勾选步骤 |
| 工作区 | 查看数据数量、清空全部业务数据 | 必须输入“清空”才能执行；保留应用设置与模型连接 |
| 维护 | 下载空白 Excel 模板、导入技术 JSON 数据包、查看尚待处理的旧版本数据提示 | 日常录入不必使用 JSON；模板可以使用 |

## 3. 推荐第一次这样使用：从零亲手测试

下面全部数字是本说明专用的 synthetic 演示数据，不是企业真实资料，也不会因为阅读本说明而自动写入程序。

### 第一步：进入空白对话

点击“＋ 新对话”。如果是首次运行且没有用户资料，应看到空白首页；如果已有历史项目，新对话仍可从空白开始，历史不会被删除。

如出现旧版本迁移提示：

- “保留旧项目继续使用”：转换可识别的旧数据，迁移前备份。
- “移入回收站，从空白开始”：旧项目转换后进回收站，正常列表从空白开始。
- “暂不处理”：不转换旧数据；旧文件保留。

迁移不保证所有旧草稿都可原样转换，无法识别的内容仍留在旧文件中。不要把迁移提示里的旧演示项目当成本次新建案例。

### 第二步：先告诉它几何

发送：

> 手工测试甲，构件式玻璃幕墙，宽18m、高6m，分格宽1.2m、高1.5m。本次数据为演示数据。

查看回显应为：幕墙总宽 18m、总高 6m、分格宽 1.2m、分格高 1.5m，数据性质为演示数据。发现不对就直接更正，或打开“查看参数”填写。

### 第三步：输入线重与单价

发送：

> 立柱线重2.7kg/m，立柱单价25元/kg；横梁线重1.3kg/m，横梁单价28元/kg；都是未税价，计算材料金额。

首次会出现“确认并计算”。核对尺寸、线重、单价和计量口径，再点击该按钮，也可以回复“确认”。这只是确认本次计算采用的输入，不等于专业工程审核。

原方案预期结果：

| 项目 | 预期值 |
|---|---:|
| 立面面积 | 108.00 m² |
| 立柱总长 | 96.000 m |
| 横梁总长 | 90.000 m |
| 理论质量 | 376.200 kg |
| 已覆盖材料金额 | 9,756.00 元 |

“算型材用量”通常对应长度和质量；想要金额就明确说“计算材料金额”。仅把参数发给它，不一定立即计算。

### 第四步：调整分格并比较

发送：

> 把分格宽改为1.5m，与原方案比较。

在已经运行原方案后，系统建立调整方案；未修改项沿用原方案。此时通常无需重复首次确认。

| 指标 | 原方案：1.2m | 调整方案：1.5m | 调整−原方案 |
|---|---:|---:|---:|
| 立柱总长 | 96.000m | 78.000m | −18.000m |
| 横梁总长 | 90.000m | 90.000m | 0.000m |
| 理论质量 | 376.200kg | 327.600kg | −48.600kg |
| 材料金额 | 9,756.00元 | 8,541.00元 | −1,215.00元 |

金额下降 12.45%。差值统一为“调整方案−原方案”；负数表示减少，不能直接解释为结构可行或工程方案更优。

### 第五步：连续追问、调整与撤销

可以接着发送：

> 为什么立柱用量变了，横梁没有变？

也可以发送：

> 把调整方案的分格宽再改为2m，与原方案比较。

短句“再改成2m”在刚讨论分格宽时已实测可识别；如果前面同时聊了多个尺寸，建议写全参数名，以免指代混淆。

上述算例改为 2m 后，调整方案材料金额应为 7,326.00 元。输入“撤销”可恢复上次编辑前的参数，但已保存的计算结果不会重写，也不会自动重新计算。撤销后再发送“与原方案比较”，得到当前参数的结果。

如原方案填错，明确说“原方案幕墙总高填错了，改为9m”。不要只说“高度改一下”。当前实现会同步调整方案中仍沿用原方案的字段；已单独修改的调整字段保持其独立值，旧结果标为历史结果。

## 4. 不想聊天填数：表单、粘贴和 Excel

### 4.1 表单

空白首页点击“录入一个方案”，或已有项目点击“查看参数”。填写目标标签页，选数据性质与报价口径，点“保存”。回到对话后发送要做的任务。

首次可只填总宽和总高，要求“计算面积”；也可以一次把几何、两类线重和两类价格全部填完。

### 4.2 粘贴 Excel 表格

在 Excel 中选中表头和数据行，一起复制到聊天输入框发送。推荐明确表头，例如：

| 参数名称 | 数值 | 单位 |
|---|---:|---|
| 幕墙总宽 | 18 | m |
| 幕墙总高 | 6 | m |
| 分格宽 | 1.2 | m |
| 分格高 | 1.5 | m |
| 立柱线重 | 2.7 | kg/m |
| 横梁线重 | 1.3 | kg/m |
| 立柱单价 | 25 | 元/kg |
| 横梁单价 | 28 | 元/kg |

以上仍是演示数据。发送后检查导入预览，选择“这批数据是：测试／演示数据”，再点“确认导入”。粘贴并不意味着参数已经生效。

### 4.3 文件导入

底部附件入口当前接受：

| 类型 | 实际处理方式 |
|---|---|
| XLSX、XLSM、CSV | 作为方案/材料表格，先预览再确认；XLSM 仅读单元格，不执行宏 |
| PDF、TXT、MD | 加入共享资料库，供检索；不会自动当作几何与报价参数导入 |
| DOC/DOCX、旧版 XLS、图片、CAD | 当前主界面不提供这些格式的导入；可转换为合适格式，或手工录入 |

表格导入顺序：上传→有多个可识别工作表时选一个→查看识别值及行列位置→给含义不明的列选对应参数→选择“更新当前项目”或“新建项目”→选实际/演示来源→“确认导入”→发出计算要求。

特别注意：

- 有缺项也可以导入，之后在对话中补充。
- 含义不明的列默认“不导入”，要主动选择；识别失败的项目不会因此自动修好。
- “更新当前项目”不等于“更新当前正在谈的调整方案”。导入数据按表中的方案标识分配；没有明确方案名称的数据通常按原方案处理。看清预览中的“方案”列。
- 建议一次上传一份参数表，确认后再传下一份。多文件、多工作表一起上传时，确认流程更容易混淆。
- CSV 推荐保存为 UTF-8；复杂合并单元格、图片、跨表公式不保证可用。
- Excel 公式按已缓存结果读取，程序不会替 Excel 重新计算公式。关键值最好先在 Excel 中重新计算并保存，或粘贴为数值。

### 4.4 空白模板

入口：“设置 → 维护 → 下载空白 Excel 模板”。实际文件包含三张工作表：

| 工作表 | 内容 |
|---|---|
| 方案参数 | 参数名称、数值、单位、方案名称；方案名建议明确写“原方案”或“调整方案” |
| 材料报价 | 用途、名称、线重、单价、价格单位、出处、日期、税费说明 |
| 说明 | 填写提示，无业务数值 |

模板已经放好字段名和单位，但没有填入演示数值。

**目前一次选择只导入一张工作表，不会自动合并“方案参数”和“材料报价”。** 使用完整模板时，第一次上传选择“方案参数”并建立项目；再上传同一文件选择“材料报价”，选择“更新当前项目”并确认。录入调整方案报价时尤其要看预览中目标方案，最简单的方法是先导入原方案，再通过对话调整。

## 5. 缺参数时怎样继续

| 当前已有内容 | 能先做什么 | 怎样说 |
|---|---|---|
| 总宽、总高 | 立面面积 | “先计算面积” |
| 总宽高、分格宽高且可整除 | 两类型材理论长度 | “先算立柱横梁长度” |
| 有效几何＋两类线重 | 理论质量 | “暂时没有价格，先算质量” |
| 有效几何＋两类线重＋两类未税单价 | 材料金额 | “计算材料金额” |
| 原方案＋调整方案 | 两方案可用指标比较 | “与原方案比较” |
| 用户上传的资料 | 检索相关片段 | “查找立柱截面相关条文” |

缺少分格或线重时，助手可能先追问并给“先看面积”“先看立柱横梁长度”等按钮。缺少单价时可以保留质量结果；金额显示未计算，不是零元。

可以点击“暂时跳过”或回复“不知道”“先不填”。跳过只是记录当前缺项，不会自动找一个默认值。稍后补齐后重新提出目标任务。

明确零价需要额外确认。负数、零尺寸、单位不明、面积冲突可能阻断相应结果。

如果宽 15m、分格宽 1.2m，15÷1.2不是整数，当前模型不支持这种边跨处理。保留真实尺寸，可以先看面积；只有真实方案确实改变时才修改几何，不能为了软件可运行随意凑整。

## 6. 材料与报价如何复用

当前不再要求只能选择 COL-A/COL-B 等预设规格。可以直接说名称、线重和价格；未命名也能用本方案临时型材进行理论计算。

典型输入：

> 立柱名称是试用立柱甲，立柱线重2.7kg/m，立柱单价25元/kg；横梁名称是试用横梁乙，横梁线重1.3kg/m，横梁单价28元/kg。以上都是演示未税数据。

第一次建立时也可用表单填写名称，避免自然语言名称识别不准确。

复用步骤：

1. 在项目里录入材料，至少有线重。
2. “查看参数 → 材料库”，点“把……存入材料库”。
3. 打开另一个已经建立的项目，同一标签选择材料，选择用于原方案还是调整方案，点“选用”。
4. 核对复制进来的线重、报价和来源，继续计算。

库材料选入项目时会复制，不是跨项目实时联动。修改一个项目不会同步改其他项目；删除项目也不会自动删除个人材料库。

更换调整方案型材名称或线重可能产生新的材料记录，原报价可能不再关联。此时应录入新报价，或者明确说“沿用刚才的价格”。“沿用”只在本项目中寻找，不会拿别的项目价格凑数。价格是否仍有效需要你自己确认。

## 7. 规范资料检索与演示规则是两种功能

### 7.1 上传资料并查询

在聊天附件入口上传 PDF/TXT/MD，或者“设置 → 资料库”上传/导入本机文件夹。

上传后查看“总页数、可检索页数”，然后问：

> 查找玻璃幕墙立柱截面厚度要求。

返回的是相关片段、出处和位置，点击展开阅读。查询范围是当前工作区中未删除的共享资料，不是互联网，也不是当前项目专属文件夹。原问题在资料为空时提出，上传后可能出现“用刚才的问题检索”。

PDF 页码按文件页序定位；TXT/MD 的“页”是系统分段，不是原文印刷页码。未找到匹配不代表没有相关要求。

扫描 PDF、图片没有可用文字层时，目前不能 OCR。程序还会过滤文字很少的页，因此“可检索 0 页/需 OCR”不一定只意味着扫描件；短文档和字数很少的页也可能被过滤。应核对原文件文字是否可选中及内容是否完整。

资料一律标为“来源待核实、未审核”。上传正式名称的规范 PDF，也不会自动确认其版本现行、适用或形成机器核查条件。

### 7.2 手工建立演示规则

入口：“查看参数 → 核查规则”。可选参数为分格宽、分格高、板块面积、层高、幕墙总宽、幕墙总高；可选条件为小于、小于等于、大于、大于等于；填写阈值并点“添加演示规则”。

如果只想测试流程，可亲手建立以下三条 **synthetic 演示条件，均不是正式规范要求**：

| 名称 | 参数 | 条件 | 阈值 |
|---|---|---|---:|
| 测试分格宽条件 | 分格宽 | <= | 1.5m |
| 测试板块面积条件 | 板块面积 | <= | 2m² |
| 测试层高条件 | 层高 | <= | 3.6m |

创建后关闭窗口，在聊天中说“执行规则核查”。首次运行仍可能要确认输入；项目存在规则时，其他计算也会附带执行配置的规则。

本说明的 1.2m×1.5m 原方案板块面积为1.8m²，面积条件满足；改成1.5m×1.5m后为2.25m²，触发演示关注。如果没提供层高，该规则应显示待补参数，而不是通过。

零条规则是正常状态，不代表“全部通过”。目前用户界面只有演示规则编辑，正式条款覆盖仍为零；没有把上传文档自动变为正式判定的功能。

## 8. 如何导出和复核

结果卡点“下载比选表”，得到 XLSX，实际包含：

1. 比选表：原/调整方案指标、差值、范围、待确认事项和是否历史版本。
2. 输入参数与来源：输入值、两类材料与价格、来源记录。
3. 计算过程：公式、代入、结果和单位。

“更多 → 技术追溯包（ZIP）”中包含 Markdown 报告、CSV 对比表、JSON 输入快照和文件清单，适合专业复核或排查问题。当前没有独立的一键 Word/PDF 报告导出入口。

导出前先看是否提示“参数已修改，以下为上次结果”。有提示则重新计算，或明确把该报告作为历史版本保存。

## 9. 删除、恢复、清空的区别

| 想达到的目的 | 操作 | 会保留什么 |
|---|---|---|
| 换个新案例测试 | ＋ 新对话 | 旧项目和对话都保留 |
| 删除聊天记录但保留方案 | 左栏对话旁 ⋯ → 删除对话 → 移入回收站 | 项目、方案、结果仍在；可从“没有对话的项目”重新进入 |
| 移除整个测试项目 | ⋯ → 删除项目 → 核对影响数量 → 移入回收站 | 个人材料库和共享资料库保留 |
| 找回误删项目或资料 | 设置 → 回收站 → 恢复 | 恢复相应记录及关联关系 |
| 永久去掉一个已删除项目 | 设置 → 回收站 → 勾选确认 → 彻底清理 | 外部下载报告、外部备份、共享库不自动清除 |
| 移除共享资料 | 设置 → 资料库 → 删除；需要永久删除再去回收站 | 其他项目和材料保留 |
| 删除个人库材料 | 设置 → 我的材料库 → 删除 | 已复制进其他项目的材料仍保留；该库删除没有回收站恢复入口 |
| 整个应用重新变空白 | 设置 → 工作区 → 输入“清空” → 清空工作区 | 应用设置和模型连接保留；外部下载文件和备份不在范围内 |

清空或彻底清理后不能依赖“撤销”恢复。看到“未完成”提示时，说明有部分清理没有成功，应保留提示交给维护人员处理。

默认业务存储目录是应用下的 `data/workspace/`；如配置了 `MW_RUNTIME_DIR`，则使用指定位置。不要在使用中直接删除数据库或手动编辑内部文件。这里的“空白”是业务数据为空，开发目录保留测试夹具不等于系统自动载入演示案例。

## 10. 启动与模型状态

如果程序已经运行，直接使用当前浏览器地址即可。重新启动时，可在应用目录打开终端，按项目 README 提供的方式运行：

```powershell
python -m streamlit run app.py
```

在终端输出的 Local URL 打开页面；默认通常是 `http://localhost:8501`，实际地址以启动输出为准。运行期间保持该终端中的程序运行。本文不涉及重新安装或改动配置。

“设置 → 模型连接”区分：未配置、已配置但未请求、最近一次成功、最近一次失败。没有密钥或在线请求失败时，可使用本地解析和表单。已配置不代表每次请求都会成功。

在线模型启用时，输入和相关项目对话上下文会发送给模型服务商；本地资料检索和计算不等于整个聊天过程完全离线。企业数据接入需按团队已确定的部署方式使用。

本机检查可导入 Excel 处理依赖 `openpyxl`；但当前 `requirements.txt` 没有显式列出它，换新电脑时可能出现 Excel 导入、模板下载或结果导出失败。由于结果卡生成时也会构建 Excel 下载内容，该依赖缺失还可能影响结果显示。遇到此类错误应由维护人员补齐依赖，不是你的表格填错了。

## 11. 常见问题与当前限制

| 现象 | 含义和做法 |
|---|---|
| 参数录完了没有结果 | 明确发“计算面积”“计算型材用量”“计算材料金额”；首次点“确认并计算” |
| 只显示质量，没有金额 | 缺单价、报价单位/税口径不符合要求，或只要求计算用量；看追问与依据 |
| 上传文件后没改变方案 | 还在预览，需“确认导入”；PDF/TXT/MD是资料而非参数导入 |
| 完整模板只有部分内容导入 | 当前一次选择一个工作表，需再次上传导入另一表 |
| 说了“核查”却得到条文片段 | 资料查询与规则核查意图不同；已配置规则时明确说“执行规则核查” |
| 缺规则参数但成本结果存在 | 独立可算结果可以保留，不代表规则已通过 |
| 撤销后看到原来的金额 | 撤销只改草稿，发“与原方案比较”重新计算 |
| 明明有资料却搜不到 | 换关键词，检查可检索页数、文字层与被过滤的短页；检索不是完整规范覆盖 |
| 删除对话后项目还在 | 这是当前设计；要移除项目使用“删除项目” |
| 删项目后规范和个人材料仍在 | 两个库是工作区共享资源，要分别删除或清空工作区 |
| 不知道“再改一下”指向谁 | 尽量写“调整方案分格宽改为……”；有调整方案时未明确对象的修改通常指向调整方案 |
| 想比较第三个方案 | 当前只支持一个原方案＋一个调整方案；可重复调整并看历史或另建项目，没有三个方案并排比较 |
| 想中途停止或取消在线请求 | 当前没有可靠的中途停止入口；等待本轮完成，避免重复发送 |
| 想自动读 CAD、图片或扫描图纸 | 当前不支持，需人工提取可用参数 |

资料库、个人材料库、回收站是本地单用户工作区功能，不应当作多人权限隔离系统。当前也没有面向工程师的正式条款审批、专业复核签署或多用户协作界面。
