# 01 页面原型说明

版本：v0.2。以桌面浏览器中的 Streamlit 应用为目标，采用文字原型；本阶段不制作可运行界面。对应功能 F01—F13，F14—F16 为后续能力。

## 1. 页面结构和共同规则

固定侧栏依次为“案例与数据”“方案工作台”“对比结果”“证据与过程”“历史与导出”。顶部显示案例名、数据包版本、当前草稿／已保存方案版本、在线模型或本地模式。页面内按钮使用业务名称，工具 ID、哈希等仅在复核详情中展示。

所有结果页常驻三项提示：**数据来源、计量范围、核查覆盖**。主演示显示“演示数据｜立柱横梁理论材料成本｜3 条演示规则，0 条正式条款”。混合数据同时显示来源构成及缺口；不能只显示一个绿色“已确认”。

设计参考宽度为 1440 px；窄屏上下堆叠，长表允许横向滚动，控件不得覆盖。状态有文字和图形提示，不只靠红绿区分。金额右对齐，单位放在列名或控件旁，不让用户推断单位。

## 2. P01 案例与数据

| 区域／控件 | 内容和默认值 | 操作与反馈 |
|---|---|---|
| 数据包卡片 | 包名、版本、来源构成、启用时间、案例数 | 可展开文件完整性和规则覆盖；不显示虚构企业名称 |
| 案例选择 | 默认 DEMO-CW-001；S0 为基准 | “载入案例”生成工作草稿，固定当前数据包版本 |
| 演示预设 | 完整分格调整、缺参演示、换规格对照 | 选择预设前说明它会新建草稿，不覆盖已保存方案 |
| 文件导入 | 单个 JSON 数据包；本地目录通过受控选择读取 | 先“校验数据包”，显示错误路径和行号／字段名 |
| 导入预览 | 新旧案例、规格、价格基准、规则及来源变更 | 有结构错误时“启用新版本”禁用；pending 非必需字段显示警告 |
| 启用按钮 | 仅验证通过后可用 | 新版本一次性启用；旧包保留；当前草稿继续绑定旧包，用户显式新建才使用新包 |

空态：没有有效数据包时，提供“载入内置演示包”和“导入数据包”。导入失败不清空现有数据。正式规范库为空是合法状态，显示“正式核查暂不可用”，不拦截演示材料计算。

## 3. P02 方案工作台

从上到下依次是任务入口、自然语言需求、前后参数表、追问区、计算范围与确认区。参数表占主要空间，对话不是唯一入口。

| 区域 | 内容 | 状态规则 |
|---|---|---|
| 任务选择 | 规范查询／辅助核查、理论长度、型材质量、成本比选；默认成本比选 | 改入口重新计算字段门槛，不丢失已经录入的值 |
| 自然语言输入 | 示例“把分格宽度从 1.2 m 改成 1.5 m” | “识别调整”只生成草案，未确认前不能运行或覆盖基准 |
| 参数表 | 参数、基准值、候选值、单位、来源、使用状态 | 基准只读；候选可编辑；显示继承、修改、显式清空、缺失、冲突 |
| 规格选择 | 立柱下拉仅 COL-A/COL-B，横梁仅 BEAM-A/BEAM-B | 线重来自所选记录；编辑线重产生草稿覆盖值并记录来源，不改材料库 |
| 价格选择 | 价格基准和版本；分别显示两个型材报价 | 未匹配到报价显示“缺少横梁报价”等，不显示 0 元 |
| 单项追问 | 一个问题、对应字段、缺失原因、输入框、提交按钮 | “稍后补充”只暂停该缺项；列表可展示其他缺项，但不同时发多道问题 |
| 计量假设 | 边柱、顶底梁计入；轴线长度；未计费用 | 明确确认本次使用；不命名为“工程师审核通过” |
| 运行确认 | 待执行模块、输入快照摘要、当前可用部分 | 必须在运行前确认；确认后输入变化即失效 |

参数行至少包括 W、H、b、h、层高、立柱规格、横梁规格、两种线重、价格基准、两个单价、计量模型。地区和核查日期仅在规则需要时要求填写。面积是只读派生值；导入文件的手填面积另列“申报面积”，发生冲突时要求处理。

### 3.1 按钮和运行门槛

| 操作按钮 | 可用条件 | 缺参时可执行的替代动作 |
|---|---|---|
| 查询依据 | 有问题文本，范围没有明确越界 | 可缺案例几何和价格；缺检索条件时返回候选并提示适用性未确认 |
| 执行辅助核查 | 已选必查清单并确认现有参数 | 缺参规则输出“待补参数”；其他规则继续，规则清单不减项 |
| 计算理论长度 | W、H、b、h、计量模型合法且整除 | 可不选型材、不填线重价格；几何不足则按钮禁用并定位字段 |
| 计算型材质量 | 长度门槛及两类有效规格、正线重齐全 | 缺线重时可按“先算理论长度” |
| 比较材料成本 | 前后方案均满足质量门槛，两个报价存在、价格口径一致，可比性通过 | 缺价格时可按“先算型材质量”；缺线重时可按“先算理论长度” |
| 运行已就绪模块 | 目标任务未就绪，但至少一个允许的模块已就绪并已确认 | 显示本次实际运行范围，运行后主任务标记“部分完成” |

在“成本比选”入口主动运行长度，不把任务自动改成已完成的长度任务；保留用户的成本目标和未决项。用户显式切换到“理论长度”入口时，长度成功可以标为该任务完成。

### 3.2 关键交互样例

| 情况 | 页面反应 |
|---|---|
| 只输入宽度调整 | 其余值从 S0 继承并标识；确认表完整展示 |
| 显式清空候选 h | 显示“待补参数”；追问“调整后分格高度是多少？请输入数值和单位。”不再继承 |
| 输入“层高 3 米” | 修改层高，不修改分格高度；含义不明则先询问目标字段 |
| 在线模型超时 | 超过 20 秒提供“使用表单继续”；保留输入文本，不编造模型回复 |
| 用户说“单元式幕墙也一样算” | 范围外提示；不会套用构件式公式 |
| 用户撤回变更 | 草稿回退到明确的先前编辑状态，增加编辑序号；不删除保存版本 |

## 4. P03 对比结果

页面顺序：范围和来源 → 模块完成情况 → 成本及用量表 → 变化因素 → 逐项核查 → 未决事项 → 版本保存与导出入口。

| 组件 | 展示内容 | 点击后的行为 |
|---|---|---|
| 模块状态栏 | 几何、长度、质量、成本、必查清单各自状态 | 缺项状态定位回对应字段，不重置其他输入 |
| 结果标题 | “已覆盖铝型材理论材料成本” | 不用“工程总价”“安全推荐方案” |
| 分项表 | 立柱／横梁长度、质量、金额；前、后、差值；合计和每平方米指标 | 每个派生值打开 P04，定位工具步骤和输入 |
| 变化说明 | 本次修改字段、金额绝对差及变化率 | 数值由计算结果绑定，模型只解释关系 |
| 核查表 | 必查项、实际输入、条件、状态、来源、人工事项 | 三项全部展示；可以筛选关注项，但显示被筛选条数 |
| 待确认事项 | 规格适用性、正式依据缺口、缺参、价格口径等 | 保留状态；用户确认参数不会消除专业确认事项 |
| 完整度说明 | “材料成本已算；正式规范未覆盖”等 | 不能用“全部通过”替代 |

主演示应显示 S0 8,899.20 元、S1 7,776.00 元、差额 -1,123.20 元、-12.62%；S1 的 R02 为演示关注项。成本下降显示“减少”，不加“最优”或“可采用”。

部分结果：缺单价时金额列为“未计算：缺报价”，质量正常显示；不合计可用金额冒充总价。成本比选口径不一致时，可查看两份单方案结果，但差值和降本表述隐藏并显示原因。

过期结果：新编辑后顶部提示“以下为上一版本结果”，禁用“导出为当前方案”；仍可进入历史以原版本身份导出。异步旧请求返回不能覆盖当前草稿结果。

## 5. P04 证据与过程

| 标签页 | 内容 | 约束 |
|---|---|---|
| 条款／规则 | 原文、证据类型、来源、条号（如有）、效力、适用范围、审核信息 | 演示规则正式字段为空；原文、摘要、模型解释分区 |
| 公式代入 | 公式版本、操作数、单位、未舍入值、展示值 | S1 立柱金额可追到 9×9=81 m、81×2.4=194.4 kg、194.4×26=5,054.40 元 |
| 输入与来源 | 字段原始输入、归一值、继承来源、确认记录、来源类型、来源状态、复核状态 | “程序计算／待专业复核”不覆盖真实输入的来源身份 |
| 覆盖与未决 | 必查清单版本、逐项结果、无正式条款说明 | 无匹配不能解释为没有要求；历史废止条款不能当现行依据 |

若来自“查询依据”而非“执行辅助核查”，页面显示候选资料，明确“尚未对方案判定”。没有规范原文时不生成仿真标准条号，不用内部测试替身填充此页面。

## 6. P05 历史与导出

列表字段：案例、方案版本、父版本、变更原因、运行 ID、运行时间、数据包版本、任务目标、结果完整度、来源摘要、专业复核状态。

| 动作 | 行为 |
|---|---|
| 查看版本 | 加载对应快照；旧规则和价格不被当前资料替换 |
| 复制为新草稿 | 保留父版本关系，可选择“沿用旧包”或显式“使用当前包并重新匹配” |
| 按原版本复算 | 新建 run，固定原数据和工具版本；版本不可用时明确失败，不自动换最新版 |
| 导出比选包 | 输出报告、CSV、JSON 快照、清单与哈希；含全部来源、规则、公式及未决项 |
| 导出部分报告 | 显式勾选“包含未完成事项”，文件标题标“部分结果” |
| 查看复核意见 | P0 展示导入资料中的已有审核信息；应用内专业意见录入列为 P1 |

## 7. 页面验收要点

P01—P05 均须可通过主流程和历史入口到达。没有模型也能录入、确认、运行、查看与导出；页面刷新不丢持久化草稿和运行结果。连续点击运行只有一条相同请求记录；修改期间的旧响应不能变成新参数结果。各具体用例见 T24—T40 及 T01—T23。
