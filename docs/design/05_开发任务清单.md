# 05 幕墙智能体开发任务清单

版本：v0.2。状态：未开始实现。本文件是开发前工作分解，不含实现代码、测试代码或建表语句。目标是可交互、可演示、可复核的铝型材理论用量与材料成本 MVP。

架构：Streamlit 负责交互，流程程序负责状态和工具调度，独立计算模块负责确定性数值，数据包与本地持久化负责来源及版本。技术选择为 Python、Streamlit、十进制运算、SQLite 与 JSON/CSV；P0 不强制向量库、网络后端或多人账号。

## 5. 里程碑与估算

| 里程碑 | 退出条件 | 规划时间 |
|---|---|---|
| M1 数据与纯计算 | DEV01—DEV04 完成；无需模型可核对全部参考数值 | 第 1—3 个工作日 |
| M2 流程与证据 | DEV05—DEV08 完成；补参、全部必查项、部分计算、降级可验证 | 第 4—6 个工作日 |
| M3 页面与交付 | DEV09—DEV12 完成；全流程、历史和导出可演示 | 第 7—8 个工作日 |
| M4 验收 | DEV13 完成；按缺陷情况修正 | 第 9—10 个工作日 |

仍采用原方案约 8—10 个工作日的初步估计，假设开发者熟悉技术且能及时获得工程顾问反馈；这不是排期承诺。测试或数据问题出现时按实际情况调整，不以删去来源、校验和追溯压缩范围。
