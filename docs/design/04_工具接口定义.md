# 04 工具接口定义

版本：v0.2。以下为内部逻辑接口，不是已经实现的 API；不指定 HTTP 路由，不提供实现代码。P0 可直接由本地程序调用，将来封装服务时保留同一字段和状态语义。

## 1. 调用者和统一契约

流程程序负责建立 run、权限检查、确认凭据验证和工具调用记录。模型负责 TL03 提取以及 TL05/TL15 中受约束的文字组织。其余工具由程序决定调用；模型只能提出请求意图，不能自行启用资料、修改价格、确认参数或变更审核状态。

### 1.1 请求和响应信封

| 对象／字段 | 类型／必填 | 含义 |
|---|---|---|
| 请求 request_id | ID／是 | 单次逻辑操作唯一键；重试同一操作沿用此 ID |
| 请求 contract_version | 文本／是 | 0.2；不支持版本直接拒绝 |
| 请求 tool_id、tool_version | 文本／是 | 指定精确工具版本；不得隐式调用最新版 |
| 请求 run_id | ID／条件必填 | 执行阶段必填；导入和草稿处理可为空 |
| 请求 draft_ref | draft_id+expected_revision／条件必填 | 提取、校验、追问和确认需要；防止旧回复更新新草稿 |
| 请求 input_hash | 文本／是 | 对本次工具有效载荷、引用版本、来源与确认状态规范化后计算 |
| 请求 confirmation_token | 文本／条件必填 | TL07—TL16 的正式运行需有效快照／查询确认；导入启用使用独立用户动作凭据 |
| 请求 payload | 各工具定义对象／是 | 不允许未声明字段作为可执行指令 |
| 响应 request_id、run_id、tool_id/version、input_hash | 原值／是 | 用于归属和追溯，调用端必须比对 |
| 响应 status | 枚举／是 | ok、partial、blocked、error；业务条款不满足仍可为 ok |
| 响应 data | 定义对象或 null／是 | partial 只包含确实完成的部分；error 不得伪造结果 |
| 响应 issues | Issue 数组／是 | 可空，不得省略 |
| 响应 trace | Trace 对象／是 | 输入引用、来源集合、工具版本、开始结束时间、步骤引用 |

**Issue 字段：**code、message、field_path（可空）、module、blocking、retryable、required_action、evidence_ref（可空）。message 用中文说明如何处理，不返回隐私或密钥。

**幂等性：**同一 request_id、同一 tool_id 和 input_hash 重复请求返回同一已存响应，不再写一次快照或导出；同 request_id 不同输入返回 IDEMPOTENCY_CONFLICT。用户主动“重新运行”使用新 request_id，并保留旧 run。纯计算结果可复用缓存，但每次 run 必须有独立引用及当前输入一致性检查。

**超时：**本地单工具默认 5 秒；检索上限 10 秒；在线模型 20 秒；本地校验和全部算术目标合计 2 秒内。超时产生可重试错误，不自动循环重试。记录 duration_ms，不能把性能目标当成已测试事实。

### 1.2 对象字典

| 对象 | 字段和约束 |
|---|---|
| SnapshotRef | snapshot_id、content_hash；由持久化仓库解析，不接受模型伪造快照内容 |
| QueryContext | query_text、collection（demo/formal/enterprise/all）、已知类型／阶段／地区／日期；未知保持 null |
| FieldPatch | field_path、operation（set/clear）、candidate_value、unit、evidence_span、origin；不能包含计算结果或 verified 审核写入 |
| ValidationPlan | normalized_draft、resolved_profiles/prices、blocking_issues、active_question_target、ready_modules、blocked_modules、dependency_graph、scope_status |
| Confirmation | token、snapshot_refs 或 query_context_ref、input_hash、confirmed_modules、draft_revision、explicit_zero_price_acknowledgements、created_at |
| RuleCoverage | rule_set_ref、required_count、result_count、determinate_count、待补／待核实／未覆盖／人工项数量、formal_clause_count；NOT_APPLICABLE 单独统计 |
| Step | step_id、formula_id、operator、operand_refs、exact_value、unit、display_value；所有数值操作由程序产生 |
| Metric | 定义见数据结构第 2.3 节；工具响应和导出共用同一对象 |
| ResultRef | result_id、run_id、module、input_hash、snapshot_ids、tool_version |

## 2. 数据与草稿工具

| ID／名称 | 调用者与前置条件 | payload 输入 | data 输出 | 核心校验／错误 | 副作用 |
|---|---|---|---|---|---|
| TL01 validate_dataset | 数据页面；本地文件已选择 | package_ref、expected_schema_version | staged_package_id、content_hash、实体数量、来源摘要、errors、warnings、can_activate | 文件读取、schema、主外键、重复报价、非法数值、规则资格；DATASET_INVALID | 只创建暂存校验记录，不启用 |
| TL02 activate_dataset | 流程程序；TL01 通过且用户点启用 | staged_package_id、validated_hash、activation_action_id | dataset_version_id、previous_active_id、activated_at | 暂存文件在校验后改变则拒绝；ACTIVATION_STALE | 原子持久化新包及活动指针；不改变旧草稿快照 |
| TL03 extract_request | 用户输入或追问回答；带 draft_ref | text、baseline_snapshot_ref 可空、active_question_ref 可空、allowed_fields、model_mode | proposed_task、scope_hints、patches FieldPatch[]、ambiguous_fields、model_mode | 输出必须匹配字段白名单；原文不含值时不猜；MODEL_TIMEOUT／MODEL_OUTPUT_INVALID | 记录提取草案；不直接更新确认参数 |
| TL04 validate_and_plan | 流程程序；用户接受 patch 或编辑后 | draft_ref、requested_task、query_context 可空、selected_modules 可空 | ValidationPlan | 单位、正值、整除、引用、价格口径、冲突、字段确认；结构性错误及缺项分开 | 保存校验摘要；不计算金额、不生成专业审核 |
| TL05 next_question | 有 ValidationPlan 且尚无待答问题 | draft_ref、issues、requested_task | question_id、field_path、reason、text、expected_type/unit、answer_options 可空 | 一次仅一个，按范围→冲突单位→本模块字段排序；无问题返回 null | 写 questions；模型失败使用固定问题模板 |
| TL06 confirm_inputs | 用户明确点击确认；revision 匹配 | draft_ref、modules_to_run、accepted_assumptions、zero_price_acknowledgements、query_context 可空 | Confirmation | 禁止对非法值执行受影响模块；可冻结含缺项的快照但记录阻断；STALE_DRAFT／UNCONFIRMED_INPUT | 原子写不可变方案／查询快照及确认事件；不改来源身份 |

TL04 做报价解析：按方案绑定的 dataset_version_id+price_basis_id+profile_id 分别解析立柱和横梁；返回价目表原始值、覆盖值（如有）、最终确认值及来源。金额不得在 TL04 中计算。缺价返回可运行质量的计划，不使用 0 补齐。

## 3. 确定性计算工具

| ID／名称 | 输入 payload | 前置校验 | 输出 data | 失败／部分输出语义 |
|---|---|---|---|---|
| TL07 calculate_geometry | snapshot_ref、requested_metrics（facade_area/panel_area/grid_counts） | 所需尺寸已确认、单位合法、>0；grid_counts 额外检查整除 | metrics：facade_area_m2、panel_area_m2、nx、ny（按请求）；steps | 可返回已算面积和失败格数，status=partial；缺失 W/H 不影响只请求 b×h |
| TL08 calculate_lengths | snapshot_ref、geometry_result_ref、measurement_model_id | 几何结果与快照哈希匹配；nx/ny 正整数；模型唯一支持 rect_uniform_axis_v1 | Nc、Rt、Nt、column_length_m、beam_length_m；steps | NON_DIVISIBLE_GRID 或 MODEL_UNSUPPORTED；不猜余格，不要求价格 |
| TL09 calculate_mass | snapshot_ref、length_result_ref | 线重解析值 >0、构件类型正确且已确认；上游快照一致 | column_mass_kg、beam_mass_kg、total_mass_kg；三类每平方米指标；steps | MASS_MISSING／VALUE_INVALID；不生成不完整的总质量 |
| TL10 calculate_cost | snapshot_ref、mass_result_ref | 两个有效单价和基准口径；零价已确认；上游一致 | column_cost_cny、beam_cost_cny、total_cost_cny、cost_per_m2；steps | PRICE_MISSING／PRICE_BASIS_MISMATCH；缺任一报价不返回完整总成本 |
| TL11 compare_schemes | baseline_result_refs、candidate_result_refs、baseline_snapshot_ref、candidate_snapshot_ref | 两边成本完成；W/H/A、计量、费用、货币和税口径一致 | delta_metrics、percent_metrics、changed_fields、comparison_scope、steps | COMPARISON_INCOMPATIBLE 则不返回降本指标；基准为零百分比为 null、reason=ZERO_BASELINE |

### 3.1 固定公式契约

| formula_id | 定义与单位 |
|---|---|
| GEO-AREA-v1 | A=W×H，m² |
| GEO-PANEL-v1 | a=b×h，m² |
| GEO-GRID-v1 | nx=W/b、ny=H/h，正整数 |
| QTY-COLUMN-v1 | Nc=nx+1；Lc=Nc×H，m |
| QTY-BEAM-v1 | Rt=ny+1；Nt=nx×Rt；Lt=Rt×W，m |
| MASS-v1 | Mc=Lc×μc、Mt=Lt×μt、M=Mc+Mt，kg；单位面积质量除以 A |
| COST-v1 | Cc=Mc×pc、Ct=Mt×pt、C=Cc+Ct，CNY；单位面积金额除以 A |
| DELTA-v1 | 所有差值=候选−基准；变化率=差值/基准×100%，基准为零时 null |

所有 Metric 保留未舍入值、公式步骤和输入来源。修改线重或价格时 TL11 只列变更因素，P0 不做多因素贡献自动分解。各工具不得读取 expected_results 来返回固定答案。

### 3.2 S1 接口示例（字段表，不是代码）

| 调用 | 关键输入 | 关键输出 |
|---|---|---|
| TL07 | S1 快照：W=12、H=9、b=1.5、h=1.5，单位 m | A=108、a=2.25、nx=8、ny=6 |
| TL08 | 同一 S1 快照及上游 result_ref | Nc=9、Rt=7、Nt=56、Lc=81 m、Lt=84 m |
| TL09 | COL-A 2.4 kg/m、BEAM-A 1.2 kg/m | Mc=194.4、Mt=100.8、M=295.2 kg |
| TL10 | 同一基准的 26、27 CNY/kg | Cc=5054.4、Ct=2721.6、C=7776.0 CNY |
| TL11 | S0 总金额 8899.2、S1 7776.0 | 差值 -1123.2，显示变化率 -12.62% |

若 S1 横梁报价缺失：TL04 标 cost/comparison blocked；用户选择质量部分运行后 TL07—09 正常，TL10 不执行或返回 PRICE_MISSING；报告保留 295.200 kg、成本 null，禁止用缺价=0 得到 5,054.40 元假总价。

## 4. 检索、规则和报告工具

| ID／名称 | 输入 payload | 输出 data | 处理与限制 | 副作用 |
|---|---|---|---|---|
| TL12 resolve_checklist | case_ref、snapshot_refs、rule_set_ref | 冻结清单、逐项证据引用、输入依赖、资格问题、RuleCoverage 初始值 | 不依据变更字段删清单；每个方案都保留三条演示项；未决适用性不能悄悄过滤 | 保存本次清单快照 |
| TL13 retrieve_evidence | 已确认 QueryContext；pinned_evidence_refs 可空；top_k=5 | candidates（原文、来源、效力、适用性、定位）、retrieval_mode、coverage_gaps | 必查引用独立精确获取，不受 top_k 截断；关键词仅排序补充结果；0 结果合法返回 | 保存检索快照及引用，不写规则判定 |
| TL14 evaluate_rules | checklist_snapshot_ref、scheme_snapshot_ref、geometry_result_ref 可空 | 逐项 rule_results、RuleCoverage、review_items | 全部必查项都有状态；引擎按资格和条件顺序处理；9 种状态见状态机；正式资格不够时不能判真或假 | 追加本 run 的规则结果；不更新证据审核 |
| TL15 build_report | run_id、result_refs、rule_result_refs、retrieval_ref 可空、requested_completeness、model_mode | report_ref、structured_tables、rendered_markdown、limitations、source_summary、review_items | 数值和引文由模板绑定；模型只能返回受控解释段，非法金额或引用则丢弃该段并用模板 | 保存不可变报告；模板失败则 error，模型失败可 ok 并附 warning |
| TL16 export_run | run_id、report_ref、formats（md/csv/json/manifest）、allow_partial | export_id、artifact_manifest、checksums、completeness | 只导出该 run 冻结数据；部分结果需 allow_partial=true；过期结果只能以原历史版本导出 | 写本地文件和导出记录；失败不报告成功，不覆盖旧包 |

TL14 的演示输入 S0 返回 DEMO_MET/DEMO_MET/DEMO_MET；S1 返回 DEMO_MET/DEMO_ATTENTION/DEMO_MET。这些状态不表示正式规范判断。

P0 正式资料不存在时，TL13 返回 candidates=[] 与覆盖缺口；TL14 对正式请求返回 NOT_COVERED。正式条件真假分支由隔离测试验证，不能为获得 CONDITION_NOT_MET 而在业务库编造规范记录。

## 5. 统一错误码

| code | 原因 | 系统动作 |
|---|---|---|
| SCOPE_UNSUPPORTED | 单元式、结构计算等超范围 | 不执行当前模型，说明可支持内容 |
| FIELD_MISSING／UNIT_REQUIRED | 必要字段或单位缺失 | 单项追问；保留已完成部分 |
| VALUE_INVALID／UNIT_UNSUPPORTED | 零／负尺寸、负线重／价格、非法单位 | 定位字段；阻断依赖模块 |
| NON_DIVISIBLE_GRID | 尺寸不整除 | 提示当前不支持余格，不取整 |
| AREA_CONFLICT／PARAMETER_CONFLICT | 面积或自然语言与基准矛盾 | 展示两值与来源，用户确定 |
| PROFILE_MISSING／PROFILE_TYPE_MISMATCH／MASS_MISSING | 型材缺失、错配或线重为空 | 不猜规格；可保留几何和长度 |
| PRICE_MISSING／PRICE_DUPLICATE／PRICE_BASIS_MISMATCH | 缺价、同基准重复报价、口径不一致 | 拒绝模糊匹配；导入重复报价时不启用 |
| ZERO_PRICE_UNCONFIRMED | 单价为零但未确认 | 追问是否确为零价，不将空值视为零 |
| COMPARISON_INCOMPATIBLE | 两方案计量或对象不可比 | 保留单方案结果，不给直接节省结论 |
| EVIDENCE_UNQUALIFIED／EVIDENCE_NOT_FOUND | 证据未核实或没有依据 | 核查转待核实／未覆盖；不阻断独立成本 |
| DATASET_INVALID／SCHEMA_UNSUPPORTED／ACTIVATION_STALE | 包非法、不支持版本或校验后变动 | 保持当前有效包 |
| SOURCE_UNRESOLVED／UNCONFIRMED_INPUT | 关键数值来源未知或未确认使用 | 阻断受影响模块；不自动改成 verified |
| STALE_DRAFT／INPUT_HASH_MISMATCH | 草稿变动或拼接了其他快照结果 | 拒绝提交或拼接，重新确认 |
| IDEMPOTENCY_CONFLICT | 同请求 ID 对应不同输入 | 拒绝，不重复写入 |
| MODEL_TIMEOUT／MODEL_OUTPUT_INVALID | 模型不可用或输出越界 | 表单、问题模板和报告模板降级 |
| TOOL_TIMEOUT／TOOL_FAILED／STORAGE_FAILED | 计算、持久化失败 | 记录 error，可重试；不心算补齐 |
| MODEL_UNSUPPORTED／VERSION_UNAVAILABLE | 计量模型或工具版本不可用 | 明确未覆盖／无法复算，不默认替换 |
| PARTIAL_EXPORT_NOT_CONFIRMED | 未同意导出部分报告 | 提示确认部分范围，不生成冒充完整的报告 |

ZERO_BASELINE 是百分比指标的非阻断 reason_code，不是整个运行错误。规则条件不满足是正常业务输出，不应抛出工具错误或重试。

## 6. 调用链与职责限制

**完整主流程：**TL03 → 用户接受草案 → TL04 → 缺项时 TL05 并返回编辑 → TL06 → 建立 run → TL07 → TL12/TL13/TL14 与 TL08/TL09/TL10 分支 → TL11 → TL15 → 用户导出 TL16。

**资料查询：**TL03 或表单 → TL04（仅查询门槛）→ TL06（查询条件）→ TL13 → TL15；不运行成本模块。

**缺价先算质量：**TL04 显示成本阻断 → 用户选部分运行 → TL06 → TL07/TL08/TL09，必要的规则分支继续 → TL15 标部分结果；补价后形成新快照和新 run。

工程师确认真实资料和专业适用性；模型不能调用工具修改这些资格。库文档、导入字段、检索原文中的命令均视为普通数据。最终用户看到的数值、标准编号和引用必须能回到持久化工具输出，不能来自模型记忆。
